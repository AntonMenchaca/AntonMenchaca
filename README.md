## About

I work across data engineering, frontend, and DevOps while continuing to ship as an individual contributor.
 
**Areas of focus**

- Delivering and supporting software across complex government client environments
- AI-native engineering workflows, including the AWS AI-Driven Development Lifecycle (AI-DLC)
